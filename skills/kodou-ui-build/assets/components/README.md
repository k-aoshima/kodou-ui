# 部品の見本

見本帳（catalog/index.html）から、部品ごとに切り出した見本です。`tools/build-assets.py` が書き出すので、手で直さないでください。

作るときは、使う部品のファイルだけを読み、HTML と最後の `<script>` の JS を写します。共通の CSS と関数は `../tokens.css`・`../kodou.css`・`../virt.js`・`../ledbar.js`・`../kodou.js`・`../icons.js` で、この順に読みます。使いどころと決まりは `../../references/components.md` にあります。

| 種類 | 部品 | ファイル | 決まりの要点 |
|---|---|---|---|
| 操作 | [ボタン](button.html) | `button.html` | 押すと起きることを、そのまま名前にします。 |
| 入力 | [テキスト入力](input.html) | `input.html` | 打つたびに確かめ、何が駄目でどう直せばよいかをその場で出します。 |
| 入力 | [テキストエリア](textarea.html) | `textarea.html` | 行番号を付け、決まりがある行（1行目は50字まで、など）は守れていない行の番号に ! を付けて色も変えます。 |
| 入力 | [数値](number.html) | `number.html` | ボタンでも、矢印キーでも、直接打っても変えられます。 |
| 入力 | [セレクト](select.html) | `select.html` | 開く・選ぶ・閉じるが全部キーボードでできます。 |
| 入力 | [コンボボックス](combo.html) | `combo.html` | 打った分だけ候補を絞り、一致した文字に下線を引きます。 |
| 入力 | [チェック・ラジオ・スイッチ](check.html) | `check.html` | 自動で何かをする設定は、既定を「切」にし、入れたときに何が起きるかを横に書きます。 |
| 入力 | [スライダー](slider.html) | `slider.html` | LED のようなドット絵の目盛りで量を見せ、つまみはつかんで動かせます（カーソルはつかむ形）。 |
| 入力 | [タグ入力](tags.html) | `tags.html` | ⏎ か , で確定し、空欄で ⌫ を押すと最後の1つを外します。 |
| 表示 | [リスト](list.html) | `list.html` | 選んだ行は反転で示します。 |
| 表示 | [長いリスト](vlist.html) | `vlist.html` | 1万行でも、描くのは見えている行だけです。 |
| 表示 | [ツリー](tree.html) | `tree.html` | 罫線でつながりを見せ、変更のあるファイルには印を付けます。 |
| 表示 | [キーと値](kv.html) | `kv.html` | 点線でキーと値をつなぎます。 |
| 表示 | [表](table.html) | `table.html` | 見出しで並べ替え、行を選べます。 |
| 表示 | [ログの流れ](log.html) | `log.html` | 流れ続ける行は上限つきで持ち、古い行から捨てます。 |
| グラフ | [棒グラフ](chart.html) | `chart.html` | ブロックを積んだ棒で、目盛りは値と同じ縮尺です。 |
| グラフ | [折れ線](line.html) | `line.html` | 系列は色に加えて、線の種類（実線と破線）と点の形（四角とひし形）、線の端の名前でも分けます。 |
| グラフ | [点の多いグラフ](canvas.html) | `canvas.html` | 点が多いものは canvas に描き、描く幅の1列に1点まで間引きます。 |
| グラフ | [スパークライン](spark.html) | `spark.html` | 文字だけで書く小さな推移です。 |
| グラフ | [ヒストグラム](hist.html) | `hist.html` | 8分の1ブロックで端数まで描き、件数を横に出します。 |
| グラフ | [メーター](gauge.html) | `gauge.html` | 使った量を LED の帯で見せ、数字は実際の値で書きます。 |
| 状態 | [進捗バー](progress.html) | `progress.html` | 割合だけでなく、件数・かかった時間・今の対象を出します。 |
| 状態 | [スピナー](spinner.html) | `spinner.html` | 1秒未満で終わる処理にはスピナーを出しません（ちらつくだけのため）。 |
| 状態 | [バッジと状態](badge.html) | `badge.html` | 状態は色だけに頼らず、文字か記号でも分かるようにします。 |
| 通知 | [通知の帯](alert.html) | `alert.html` | 何が起きたかと、どう直すかを文で書きます。 |
| 通知 | [トースト](toast.html) | `toast.html` | 取り消せる操作は、確認を出さずにすぐ実行し、取り消しを付けて知らせます。 |
| 通知 | [空の状態](empty.html) | `empty.html` | なぜ空なのかと、最初の1件を作る方法を書きます。 |
| 移動 | [タブ](tabs.html) | `tabs.html` | 選んだタブは反転で示し、件数を添えます。 |
| 移動 | [パンくず](crumbs.html) | `crumbs.html` | パスと同じ形で、今いる場所までの道を見せます。 |
| 移動 | [ページ送り](pager.html) | `pager.html` | 今のページと全体の件数を一緒に出します。 |
| 重ね | [メニュー](menu.html) | `menu.html` | 項目の横にキーを書き、次からはメニューを開かずに使えるようにします。 |
| 重ね | [ツールチップ](tooltip.html) | `tooltip.html` | アイコンには文字を添えるのが基本で、ツールチップはキーを教えるために使います。 |
| 重ね | [ダイアログ](dialog.html) | `dialog.html` | 二重罫線の枠です。 |
| かけら | [キーの表示](kbd.html) | `kbd.html` | 1つのキー、同時に押すキー、続けて押すキーを書き分けます。 |
| かけら | [区切り線](divider.html) | `divider.html` | 実線は区切り、点線は同じまとまりの中の切れ目、二重線は大きな区切りに使います。 |
| かけら | [パネル](panel.html) | `panel.html` | 罫線の枠に、左上の名前と右上の状態、下にキーの帯を付けます。 |
| 土台 | [色・文字・余白・動き](tokens.html) | `tokens.html` | 色は端末の ANSI の並びで持ち、色相は色覚の違いがあっても見分けやすい CUD 寄りにしています。 |
