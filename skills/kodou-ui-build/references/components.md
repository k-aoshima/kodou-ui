# 部品

見本帳 `catalog/index.html` にある 36 部品と土台の使いどころ、状態、決まり、使わない場面をまとめる。見た目と動きの正本は見本帳で、ここには判断に要ることだけを書く。

## すべての部品に共通する決まり

- **枠**: 罫線の枠で囲み、名前は枠の線の上に載せる。角は丸めない。
- **選択**: 反転表示（`--sel-bg` の面に `--sel-fg` の文字）で示す。選んだ行やカードの左端に色の縦線を付けない。
- **フォーカス**: アクセント色の 2px の実線で囲む（`outline: 2px solid var(--accent); outline-offset: 2px`）。点線にしない。
- **押せる範囲**: 24px 以上にする。見た目を小さく保ちたい部品（チップの ×、小さいボタン、`[x]`、ページ送り）は、`::after` などで当たり判定だけを広げる。
- **無効**: 文字を `--faint` にし、枠を破線にして、カーソルを `not-allowed` にする。なぜ使えないかを近くに書く。
- **色だけで伝えない**: 状態、系列、境目の超過は、色に加えて文字か記号か形で示す。
- **アイコン**: 文字ラベルを添える。アイコンだけにするのは幅がどうしても足りない所だけで、そのときはツールチップと `aria-label` で名前を出す。
- **イベント**: 部品の親で1つだけ受ける。行ごとに listener を付けない。
- **見えている分だけ描く**: 項目の数が決まっていない部品（セレクトとコンボボックスの候補、リスト、ツリー、表、ログ）は、件数が少なくても見えている行だけを描く。窓の高さ（`max-height`）と行の高さを決め、行の要素は窓の行数＋数行だけ作って使い回す。DOM の並びは見た目の並びと同じにし、上下の空白で全体の高さを保つ。フォーカスは箱に置いたままにし、選んでいる行は `aria-activedescendant` で示す（行の要素は使い回されるので、行にフォーカスを置かない）。候補には `aria-setsize` と `aria-posinset` を付け、全体の件数を読み上げに渡す。作りは `assets/virt.js`（使い方は `patterns.md` の「速さと軽さ」）。
- **状態の見本**: 通常・ホバー・フォーカス・無効・エラー（入力部品）を並べて見せる。

## 操作

### ボタン
押すと起きることをそのまま名前にする（「保存する」「ブランチを切る」）。種類は通常、primary（主な操作、1画面に1つ）、danger（壊す操作）、ghost（枠なし）、大きさは sm・通常・lg。
- **枠のあるボタンに角かっこを付けない**。枠と角かっこは「押せる」という印が二重になり、幅も取る。角かっこは、枠の無い文中の小さな操作（`.btn.link`、例: 1行の中の「[取り消し]」）だけに使う。
- **ホバーはボタン自身の色を濃くする**。黒い面で反転しない。通常は地を薄く塗って枠を濃く、primary は `--blue-hover`、danger は `--red` の面に `--on` の文字。色の切り替えにトランジションは付けない。
- 時間がかかる操作は、1秒までは何も出さず、1秒を超えたら何件目かを出し、終わったら結果を出す。
- 使わない場面: 画面の移動だけならリンクかタブにする。

## 入力

### テキスト入力
ラベル、ヘルプ、接頭辞・接尾辞（`feat/`、`https://`、`.dev`）を付けられる。打つたびに確かめ、何が駄目でどう直せばよいかをその場で出す。送るまで待たせない。
- 状態: 通常、フォーカス（枠を濃く、下に 2px の線）、無効、エラー（枠を `--red`、ヘルプを `--red` の文で）。エラーは `:user-invalid` でも出す。
- 任意の欄には「任意」と書き、空のときに何が起きるかをヘルプに書く。

### テキストエリア
行番号を付ける。行ごとの決まり（1行目は50字まで、など）を守れていない行は、番号に `!` を付けて色も変える。
- 使わない場面: 1行で済む入力。

### 数値
ボタン、矢印キー、直接の入力のどれでも変えられる。範囲の端で止まったら、なぜ止まったかを出す。
- 使わない場面: 量を感覚で決めたいときはスライダー。

### セレクト
開く・選ぶ・閉じるを全部キーボードでできるようにする。閉じたまま頭の文字を打つと、その項目に切り替わる。重ねて出す部分は `popover` 属性で作る。
- 候補は見えている分だけ描く（ブランチが何百本あっても同じ要素数）。
- 使わない場面: 選択肢が3つ以下ならラジオ、数十を超えて探すならコンボボックス。

### コンボボックス
打った分だけ候補を絞り、一致した文字に下線を引く。何件中何件かを出す。候補の並びは使った回数の順に固定し、打つたびに入れ替えない。絞り込みは当たった番号の並びを作り直すだけにし、描くのは見えている候補だけにする。

### チェック・ラジオ・スイッチ
印は CSS の `:checked` で出す（`[x]` `[ ]` `(•)` `( )` の形）。自動で何かをする設定は既定を「切」にし、入れたときに何が起きるかを横に書く。

### スライダー
- 溝は LED の目盛りのようなドット絵にする。埋まった所はアクセント色の四角を隙間を空けて並べ、空いた所は `--ui` の細い線にし、値は右に等幅で出す。
- つまみはドット絵（縦長の四角に横の溝を2本）で描く。半分のブロック `▌` は使わない。
- カーソルは、つまみの上で `grab`、ドラッグ中は `grabbing`、溝の上は既定のまま。手の形（`pointer`）にしない。
- 透明な `input[type=range]` は描いた溝と同じ幅にだけ重ね、ドラッグした位置とつまみの位置をそろえる。キー操作（←→、Home/End、PageUp/PageDown）は input に任せる。
- フォーカスはつまみをアクセント色にし、実線の枠で囲む。
- 動かすと同時に、値とそれで何が変わるかを出す。

### タグ入力
⏎ か `,` で確定し、空欄で ⌫ を押すと最後の1つを外す。重なりはその場で知らせる。チップの × は押せる範囲を 24px にする。

## 表示

### リスト
選んだ行は反転で示す。`j`/`k` で動き、Space で複数選べる。並びは勝手に変えない。描くのは見えている行だけで、選択を動かしたときは、変わった2行の印だけを付け直す。選んだ状態は行の要素ではなくデータの側（番号の集合）に持つ。

### 長いリスト
リストと同じ作りで、データも行番号から要る分だけ作る。1万行でも描く行は窓の分（見本帳で 18 行）だけ。行の高さは固定にする。

### ツリー
罫線でつながりを見せ、変更のあるファイルには文字の印（`M` `A`）を付ける。←→ で開閉する。開いている分を平らな並びにして、見えている行だけを描く。並びを作り直すのは開閉のときだけ。

### キーと値
点線でキーと値をつなぐ。値はぼかさず、そのままコピーできるようにする（コピーのボタンは押せる範囲 24px）。

### 表
見出しで並べ替え、行を選べる。数字は右にそろえて桁を合わせる。描くのは見えている行だけで、見出しは `position: sticky` で上に残す。並べ替えは番号の並びを並べ直して描き直すだけで、行の要素は作り直さない。動きは並びが変わるときだけ短く付け（前に見えていた行を前の位置から滑らせる）、`prefers-reduced-motion` では止める。

### ログの流れ
流れ続ける行は上限のあるリングバッファで持ち、古い行から捨てる。描くのはリストと同じく見えている行だけで、行の要素は使い回す（上限が 2,000 行でも、要素は窓の行数＋数行で済む）。水準の絞り込みは要素を作り直さず、見せる行の並びだけを作り直す。上にさかのぼったら追いかけを止め、止めていることを出す。

## グラフ

どのグラフも、目盛りとラベルは値と同じ縮尺にし、触れると値を出す。

### 棒グラフ
ブロックを積んだ棒で描く。上限を超えた分は、色だけでなく斜線と「+分」の文字でも示す。

### 折れ線
系列は色に加えて、線の種類（実線と破線）、点の形（■ と ◇）、線の端の名前で分ける。グラフの上で動かすと、縦の線とその時刻のすべての値を出す。

### 点の多いグラフ
点が多いものは canvas に描き、描く幅の1列に1点まで間引く。列ごとに最小と最大を残し、山を消さない。

### スパークライン
文字だけで書く小さな推移。低くて値を比べにくいので、今の値と最大を数字で横に添える。

### ヒストグラム
8分の1ブロックで端数まで描き、件数を横に出す。注意する区間は色に加えて ▲ を付ける。

### メーター
使った量を目盛りで見せ、数字は実際の値で書く。境目を超えたら、色に加えて「注意」「危険」の文字でも出す。

## 状態

### 進捗バー
割合だけでなく、件数・かかった時間・今の対象を出す。手順があるものは今どこかを並べる。10秒を超える処理に使う。

### スピナー
1秒未満で終わる処理には出さない（ちらつくだけのため）。1秒を超えたら、何をしているかと件数か経過時間を添えて出す。

### バッジと状態
状態は色だけに頼らず、文字か記号でも分かるようにする。起動ログの形（`[  OK  ]` `[FAILED]`）も使える。全部大文字は短い状態の語だけにする。

## 通知

### 通知の帯
何が起きたかと、どう直すかを文で書く。エラーコードや生のログは消さずに `<details>` で折りたたんで残す。種類は色だけでなく `[FAIL]` のような文字でも示す。左端に色の帯を付けない。

### トースト
取り消せる操作は、確認を出さずにすぐ実行し、取り消しを付けて知らせる。消えるまでの残りは下の線で見せる。
- 使わない場面: 読み逃すと困る知らせ。それは通知の帯にする。

### 空の状態
なぜ空なのかと、最初の1件を作る方法を書く。

## 移動

### タブ
選んだタブは反転で示し、件数を添える。←→ で移れる。

### パンくず
パスと同じ形で、今いる場所までの道を見せる。区切りは `--deco`。

### ページ送り
今のページと全体の件数を一緒に出す。数字のボタンは押せる範囲を 24px にする。

## 重ね

### メニュー
`popover` 属性で出す。項目の横にキーを書き、次からはメニューを開かずに使えるようにする。壊す操作は区切って最後に置く。

### ツールチップ
キーを教えるために使う。アイコンだけのボタンの名前を出すときにも使い、同じ名前を `aria-label` にも入れる。CSS だけで動かす。

### ダイアログ
二重罫線の枠の `<dialog>`。画面を止めるので最後の手段にし、取り消せない操作のときだけ使う。ふつうの確認はその場の1行（`y/N`）で済ませる。既定はいつも安全な側（`y/N` の N、「やめる」）にし、何が消えて戻せないのかを具体的に書く。

## かけら

### キーの表示
1つのキー、同時に押すキー（⌘⇧N）、続けて押すキー（g g）を書き分ける。

### 区切り線
実線は区切り、点線は同じまとまりの中の切れ目、二重線は大きな区切りに使う。

### パネル
罫線の枠に、左上の名前、右上の状態、下にキーの帯を付ける。すべての部品の入れ物。

## 土台

### トークン
SKILL.md の「トークン」の表を見る。見本帳では各色の下に地とのコントラスト比を出している。

### 速さと軽さ
見本帳は自分の値（キー入力から描画までの時間、要素の数、ヒープ）をステータスラインに出す。作る画面でも同じ値を出せるようにする。作り方は `patterns.md` の「速さと軽さ」にある。
