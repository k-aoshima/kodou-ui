第2章

文字の
読みやすさ

同じ文でも、大きさと並べ方で読みやすさが変わります。

  • 読みやすい字の大きさがわかる
  • 1行の長さと行の高さの目安がわかる
  • 大文字だけにしてよい所がわかる
4つの単元

字の大きさと並べ方

2-1字を小さくしすぎない

小さい字ほど読みにくさが一気に増す

  • 好まれるパソコンで 18px くらい
  • 小さい字書体しだいで最大 50% 遅くなる
くわしく

液晶の画面で好まれた字の大きさは、目から見た角度で 32〜33 分でした[1]。ふつうの画面を 50cm 離れて見るなら、だいたい 18px です（この換算は目安）。読める限界に近い小さな字では、書体によって読む速さが最大 50% も違いました[2]。ふつうの大きさなら、差は 5% ほどです。

2-21行を長くしすぎない

文は1行 40字まで、行の間はゆったり

  • 1行日本語なら 40字まで
  • 行の高さ字の大きさの 1.5倍以上
くわしく

Web の読みやすさの基準（WCAG）は、1行を英語で 80字、日本語で 40字までにし、行の高さを字の大きさの 1.5 倍以上にするよう勧めています[3]。実験では長い行の方が速く読めることもありますが、人が好むのは中くらいの長さでした[4]。一覧や表は、1行を目で追うより列で拾うので、幅いっぱいに使ってかまいません。

2-3読む字と、そろえる字

文はふつうの字、数字やコマンドは等幅

  • 説明の文字の幅がばらばらの書体
  • 数字・表全部同じ幅の書体（桁がそろう）
くわしく

ふつうの大きさの文なら、どちらの書体でも読む速さの差は小さいです[2]。それでも分けるのは役目が違うからです。文は流れるように読み、数字やコマンドは縦に桁をそろえて見比べます。日本語では、ゴシック体が明朝体より速く読めたという結果もあります[5]。

2-4大文字だけは短い語に

OK・ERROR はいい、長い文はダメ

  • 短い語大文字だけでいい
  • 長い文大文字だけにしない
くわしく

小さい字では、大文字だけの方が速く読めたという実験があります。ただし字を大きくすると差は消えました[6]。ひと目で単語を見分ける実験では、小文字の方が 26% 長くかかりました。これは単語1つの話で、文や長い見出しを大文字だけにするのは勧められていません[7]。

さわって確かめる

大きさと行の長さを変えてみる

画面の文字は、紙の本よりも少し大きめにした方が読みやすくなります。1行が長すぎると、次の行の頭を探すときに目が迷い、同じ行を二度読んでしまうことがあります。行と行の間を少し空けるだけで、文の区切りが見つけやすくなり、長い説明でも最後まで読み通しやすくなります。

「読みにくい例」は 11px・80字・行の高さ 1.2倍です。

この章のまとめ

3つだけ覚えて帰る

  • 1字は小さくしすぎない
  • 2文は 1行 40字まで・行の高さ 1.5倍以上
  • 3大文字だけにするのは短い語だけ
POINT
迷ったら、字は大きく、行は短く。
